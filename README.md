# QX Signal Pro 📈

**Quotex M1 ক্যান্ডেল-রিয়েকশন সিগন্যাল ওয়েব অ্যাপ** — টিক-লেভেল ডেটা দিয়ে "মানুষের চোখের" ক্যান্ডেল রিডিং স্কোরিং ইঞ্জিন। Python (FastAPI) + vanilla JS ফ্রন্টএন্ড, Railway-তে deploy করার জন্য তৈরি।

---

|---|---|
| **🏠 হোম** | কানেকশন স্ট্যাটাস, ব্যালেন্স, লাইভ পেয়ার কার্ড (প্রাইস + কাউন্টডাউন + মিনি ক্যান্ডেল), চলমান সিগন্যাল, ক্যান্ডেল-রিয়েকশন গাইড |

| **🕐 হিস্টোরি** | সিগন্যাল হিস্টোরি WIN/LOSS ব্যাজ সহ — লাস্ট ১ ঘন্টা (ডিফল্ট), ৩h/৬h/২৪h/সব; পেয়ার/CALL-PUT/রেজাল্ট ফিল্টার |
| **📊 স্ট্যাটস** | প্রতি পেয়ারে আলাদা উইন-রেট, **CALL বনাম PUT আলাদা উইন-রেট**, কনফিডেন্স-টিয়ার উইন-রেট, ব্যাকটেস্ট বাটন |
| **⚙️ সেটিং** | QX টোকেন (SSID) পেষ্ট করে লাইভ কানেকশন, ডেমো/রিয়েল, পেয়ার সিলেকশন, মিনিমাম কনফিডেন্স |

## 🧠 সিগন্যাল ইঞ্জিন (৮-ফ্যাক্টর কনফ্লুয়েন্স)

প্রতিটি M1 ক্যান্ডেল ক্লোজে পরের ক্যান্ডেলের প্রেডিকশন — স্কোর −১৩২ থেকে +১৩২:

1. **Body strength** — |close−open| ÷ range (≥৭০% = শক্তিশালী)
2. **Wick rejection** — পিন বার (৫৫%+ উইক)
3. **Trend** — EMA9 বনাম EMA21
4. **Streak** — একটানা ক্যান্ডেল (৩-৪ = কন্টিনিউ, ≥৫ = exhaustion fade)
5. **Market structure** — HH/HL বনাম LH/LL (swing থেকে)
6. **Level** — সাপোর্ট/রেজিস্ট্যান্সে রিজেকশন বা ব্রেক
7. **Micro** — টিক ডেল্টা + **শেষ ১০ সেকেন্ডের মোমেন্টাম** + ক্লোজের অবস্থান
8. **Volatility** — ATR-এক্সপ্যানশন কন্টিনিউ / স্কুইজ ড্যাম্পনার

|score| ≥ ৩৫ + কনফিডেন্স ≥ সেটিং → **CALL/PUT**, নাহলে **NO SIGNAL** (কনফ্লুয়েন্স না মিললে ট্রেড না)।

**ফ্লিপ-রিস্ক ডিটেক্টর:** রানিং ক্যান্ডেলের বডি < ১৮% + শেষ ১০ সেকেন্ডে উল্টো মোমেন্টাম > ৫০% হলে UI-তে ⚠ সতর্কতা (৫৭-৫৮ সেকেন্ড রেড → শেষ ২ সেকেন্ডে গ্রিন — এই ফেনোমেনার ডিটেকশন)।

## ⚡ রিয়েল-টাইম পারফরম্যান্স

- **টিক স্ট্রিম:** Quotex WS থেকে ~৭-১২ টিক/সেকেন্ড/পেয়ার — প্রতিটি টিক সাথে সাথে (~৪০ms গার্ড-ফ্লোর সহ) ব্রাউজারে ফরওয়ার্ড হয়
- **রেন্ডারিং:** ৬০fps `requestAnimationFrame` লুপ; টিকের মাঝে রানিং ক্যান্ডেলের ক্লোজ/হাই/লো **এক্সপোনেনশিয়াল ইন্টারপোলেশনে** গ্লাইড করে — জাম্প নয়, ভিডিওর মতো মোশন
- **কাউন্টডাউন:** ওয়াল-ক্লক থেকে প্রতি ফ্রেমে হিসাব (সার্ভারের seconds_left-এ সিঙ্ক) — কখনো ড্রিফ্ট করে না
- **পেয়ার সুইচ:** DB-র পুরো হিস্ট্রি + লাইভ ইঞ্জিন মেমরি মার্জ করে সাথে সাথে ফুল চার্ট — চার্ট ভাঙে না, রাইট-অ্যালাইনড প্রফেশনাল লেআউট
- **লেটেন্সি:** টিক → ব্রাউজার পেইন্ট সাধারণত < ২০ms (একই রিজিয়নে)

## 🚀 Railway Deploy (ধাপে ধাপে)

### ১. কোড নাও
এই ফোল্ডারটা (`qx-signal-pro/`) একটা নতুন GitHub রিপোতে push করুন:

```bash
cd qx-signal-pro
git init && git add . && git commit -m "QX Signal Pro"
git remote add origin https://github.com/<user>/qx-signal-pro.git
git push -u origin main
```

### ২. Railway তে অ্যাপ বানান
1. [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo** → রিপো সিলেক্ট
2. Railway Python অটো-ডিটেক্ট করবে (`runtime.txt` + `Procfile` দেওয়াই আছে)
3. **Settings → Networking → Generate Domain** দিয়ে পাবলিক URL নিন

### ৩. টোকেন সেট করুন (দুইভাবে)
- **পথ ১ (সহজ):** অ্যাপ খুলে → **⚙️ সেটিং ট্যাব** → `ssid` টোকেন পেষ্ট → সেভ। টোকেন SQLite-এ সেভ হয়।
- **পথ ২ (env):** Railway **Variables**-এ:
  ```
  QX_TOKEN=আপনার_ssid_টোকেন
  QX_IS_DEMO=1
  QX_PAIRS=EURUSD_otc,USDJPY_otc,AUDUSD_otc,GBPUSD_otc
  ```
  ⚠️ env টোকেন UI-র টোকেনকে override করে।

### ৪. ডেটা কায়েম রাখতে (অপশনাল কিন্তু recommended)
SQLite ফাইল container restart হলে মুছে যায়। History/স্ট্যাটস রাখতে:
**Settings → Volumes → New Volume**, mount path: `/app/data`

### ৫. টোকেন কোথায় পাবেন
1. ব্রাউজারে [qxbroker.com](https://qxbroker.com) **লগইন থাকুন** (লগইন ট্যাব খোলা রাখুন)
2. `F12` → **Application** → **Cookies** → `https://qxbroker.com`
3. `ssid` নামের cookie-র **Value** কপি (একটা লম্বা alphanumeric স্ট্রিং)
4. সেটিং ট্যাবে **📋 পেষ্ট বাটন** চাপুন (এক ক্লিকেই বসে যাবে) বা ফিল্ডে পেষ্ট করুন → **সেভ ও কানেক্ট**

> ⚠️ **SSID টোকেন সেশন-বাউন্ড — কিছুক্ষণ/কয়েক ঘণ্টা পর expire হয়।** Quotex থেকে লগআউট, অন্য ডিভাইসে লগইন, বা সেশন শেষ হলে পুরনো টোকেন মরে যায়। টোকেন reject হলে সেটিং ট্যাবে **লাল ব্যানার** দেখাবে: "টোকেন প্রত্যাখ্যাত — expire হয়ে গেছে" — তখন আবার নতুন ssid কপি করে পেষ্ট করলেই অ্যাপ সাথে সাথে রিকানেক্ট হয়।
>
> মোবাইলে পেষ্ট করতে সমস্যা হলে **📋 পেষ্ট বাটন** ব্যবহার করুন — ক্লিপবোর্ড থেকে সরাসরি এক ট্যাপে বসে যায়।

## 🖥️ লোকাল রান

```bash
cd qx-signal-pro
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8000
# ব্রাউজার: http://localhost:8000
```

টোকেন না দিলে অ্যাপ **ডেমো ফিড** (সিন্থেটিক টিক) নিয়ে পুরো সিস্টেম দেখায় — UI-তে "ডেমো ফিড" ব্যাজ থাকে।

## 🧪 ব্যাকটেস্ট

- **অ্যাপে:** 📊 স্ট্যাটস ট্যাব → "ব্যাকটেস্ট চালাও" — সার্ভারে জমে থাকা সব ক্যান্ডেলে একই ইঞ্জিন রিপ্লে হয়
- অ্যাপ যতক্ষণ চালু থাকে, লাইভ ফিড থেকে ডেটা নিজে নিজে জমতে থাকে — ব্যাকটেস্ট স্যাম্পল বড় হতে থাকে
- No-lookahead: ক্যান্ডেল N-এর সিগন্যাল শুধু N পর্যন্ত ডেটা ব্যবহার করে, N+1-এ settle হয়

## ⚠️ ঝুঁকি সতর্কতা (পড়ুন!)

- **কোনো সিস্টেমই নেক্সট ক্যান্ডেল ১০০% বলতে পারে না।** যে বলে, সে মিথ্যে বলে। এই অ্যাপ প্রোবাবিলিস্টিক কনফ্লুয়েন্স স্কোর দেয় — ৫০-৬৫% রেঞ্জের এজ-ই বাস্তবসম্মত লক্ষ্য।
- বাইনারি অপশন অত্যন্ত ঝুঁকিপূর্ণ; OTC ফিড ব্রোকার-নিয়ন্ত্রিত। শুধু সেই টাকা দিয়ে টেস্ট করুন যা হারালে ক্ষতি হবে না।
- এই টুল **ট্রেড করে না** — অ্যানালাইসিস দেয়। ট্রেড আপনি Quotex প্ল্যাটফর্মে নিজে করবেন।
- প্রথমে ডেমো একাউন্টে অন্তত ১-২ সপ্তাহ Stats ট্যাবে নিজের উইন-রেট যাচাই করুন, তারপরই ভাবুন রিয়েল পেয়ারে।

## 🔧 আর্কিটেকচার

```
main.py                 FastAPI entry (lifespan: DB + core start)
app/
  quatex/client.py      Quotex WS ক্লায়েন্ট (EIO=3, binary events, auto-reconnect)
                        + DemoFeed (টোকেন না থাকলে সিন্থেটিক টিক)
  engine/candles.py     টিক → M1 ক্যান্ডেল + মাইক্রো-স্ট্রাকচার (last-10s, flip-risk)
  engine/analysis.py    ৮-ফ্যাক্টর স্কোরিং (EMA/ATR/swings/S-R)
  engine/signal.py      কনফ্লুয়েন্স ডিসিশন + সিগন্যাল লাইফসাইকেল
  engine/tracker.py     WIN/LOSS settle + স্ট্যাটস
  backtest/runner.py    হিস্টোরিক্যাল রিপ্লে ব্যাকটেস্ট
  api/                  REST + WebSocket hub
  storage.py            SQLite (candles, signals, settings)
static/                 SPA ফ্রন্টএন্ড (TradingView Lightweight Charts™ ভেন্ডর্ড, কোনো CDN নেই)
```

**কানেকশন প্রোটোকল** (live-verified): `wss://ws2.qxbroker.com/socket.io/?EIO=3&transport=websocket` → auth `42["authorization",{"session":...}]` → `instruments/follow` → `quotes/stream` binary ticks → `history/list/v2` — যার পেলোডে `history` (লাস্ট ~500s টিক) **এবং `candles` (~200টি সার্ভার-কম্পিউটেড M1 OHLC, newest-first)** দুটোই থাকে।

**ক্যান্ডেল-প্যারিটি আর্কিটেকচার** (আসল Quotex ক্যাপচার ডেটায় ব্যাকটেস্টেড, 100% OHLC মিল প্রমাণিত):
- সার্ভারের `candles` অ্যারের **শেষ ১-৩টি রো stale mid-minute স্ন্যাপশট** হয় (যেমন: মিনিটের ৪ সেকেন্ডের স্ন্যাপশটে টিকস=৮, অথচ পূর্ণ মিনিটে ~১৪০ টিক)। Quotex টার্মিনাল নিজেও লাইভ-এজ টিক-স্ট্রিম থেকে আঁকে, সার্ভার-রো শুধু পুরনো হিস্ট্রির জন্য — অ্যাপ এখন হুবহু সেটাই করে:
  - `last_ts ≥ minute+50` → **COMPLETE রো** = authoritative (ইঞ্জিন ওভাররাইট হয়)
  - `last_ts < minute+50` → **STALE রো** = শুধু অনুপস্থিত মিনিট ফিল করে; লোকাল লাইভ-কালেক্টেড ক্যান্ডেল কখনো ওভাররাইট করে না
- **পিরিয়ডিক রিসিঙ্ক** (~৪৫s/পেয়ার): সার্ভার থেকে authoritative ক্যান্ডেল বারবার রি-মার্জ হয় — মিসড টিকের H/L নিরাময়, DB-তে সংশোধন সেভ, ব্রাউজারে রিব্রডকাস্ট
- **সংশোধিত ক্লোজে WIN/LOSS re-settle**: সার্ভার কোনো ক্লোজড ক্যান্ডেলের ক্লোজ ঠিক করলে সিগন্যালের ফলাফলও সংশোধন হয়ে ব্রডকাস্ট হয়
- **লেট-টিক গার্ড**: মিনিট-সীমানা পেরোনো ব্যাচের পুরনো টিক নিজের ক্লোজড ক্যান্ডেলে যায়, রানিং ক্যান্ডেল দূষিত হয় না
- **সার্ভার-ক্লক সিঙ্ক**: প্রতি টিকের ts থেকে smoothed offset — কাউন্টডাউন/মিনিট-বাউন্ডারি সার্ভার-টাইমে চলে
- **লোকাল টাইমজ়োন টাইম-অ্যাক্সিস**: চার্টের সময়-লেবেল আপনার লোকাল টাইমে — Quotex টার্মিনালের মতোই

**ব্যাকটেস্ট ফলাফল** (আসল Quotex ক্যাপচারড ডেটা, ৩ পেয়ার × 197 COMPLETE সার্ভার-ক্যান্ডেল):
- প্যারিটি: COMPLETE মিনিটে **17/17 (100%)** ইঞ্জিন OHLC == সার্ভার OHLC; লাইভ-এজ মিনিটে **6/6 (100%)** টিক-ট্রুথ সংরক্ষিত; পুরনো কোড ৩টি মিনিট নষ্ট করত
- সিগন্যাল: 199 সিগন্যাল → 106W/91L/2T = **53.8% winrate** — স্যাম্পল ছোট (~২ ঘণ্টার ডেটা/পেয়ার), এজ-দাবির জন্য যথেষ্ট নয়; অ্যাপ চলতে থাকলে DB-তে ডেটা জমে বড় স্যাম্পলে `/api/backtest` চালান

## ❓ FAQ / ট্রাবলশুটিং

**টোকেন দিলেও লাইভ ডেটা আসছে না?**
৯৯% ক্ষেত্রে **টোকেন expire হয়েছে**। Quotex সার্ভার তখন `authorization/reject` পাঠায় — অ্যাপ সেটিং ট্যাবে লাল ব্যানারে দেখায়: **"❌ টোকেন প্রত্যাখ্যাত — SSID টোকেনটি expire হয়ে গেছে"**। সমাধান: qxbroker.com **লগইন থাকা অবস্থায়** নতুন ssid কপি → সেটিং ট্যাবে পেষ্ট → সেভ ও কানেক্ট। সেভ করার পর ~১০-১৫ সেকেন্ডে ফলাফল দেখায়: ✓ লাইভ কানেক্টেড (সবুজ) বা ✗ প্রত্যাখ্যাত (লাল)।

**টোকেন পেষ্ট করা যাচ্ছে না?**
- **📋 পেষ্ট বাটন** চাপুন — ক্লিপবোর্ড থেকে এক ট্যাপে বসে যায় (মোবাইলেও)
- সরাসরি করতে চাইলে: ফিল্ডে ট্যাপ → লং-প্রেস/Ctrl+V → **দেখাও** বাটনে চেক করুন বসেছে কি না
- ফিল্ড পেষ্টের পর সেভ করলে খালি দেখাবে (নিরাপত্তার জন্য) — এটা স্বাভাবিক, প্লেসহোল্ডারে "সেভ করা আছে: r5H…" লেখা থাকবে

**"ডিসকানেক্টেড" দেখাচ্ছে?**
টোকেন reject হলে "❌ টোকেন প্রত্যাখ্যাত (expired)" লেখা আসবে — নতুন টোকেন নিন। শুধু নেটওয়ার্ক ড্রপ হলে অ্যাপ নিজে রিকানেক্ট করে।

**সিগন্যাল আসছে না?**
ভালো ব্যাপারের লক্ষণও হতে পারে — কনফ্লুয়েন্স কম হলে অ্যাপ ইচ্ছাকৃতভাবে NO SIGNAL দেয়। কনফিডেন্স ফিল্টার কমাতে চাইলে সেটিং ট্যাব।

**উইন-রেট ৫০%-এর নিচে?**
স্যাম্পল ছোট হলে ওঠানামা স্বাভাবিক। অন্তত ১০০+ সিগন্যাল জমার পর সিদ্ধান্ত নিন; কনফিডেন্স টিয়ার অনুযায়ী দেখুন — strong টিয়ারে এজ থাকা উচিত।

**রিয়েল মোড?**
সেটিং-এ একাউন্ট "রিয়েল" বেছে নিন — ডেটা/সিগন্যাল একই, শুধু ব্যালেন্স ডিসপ্লে আলাদা। ট্রেড আপনি নিজে নেবেন।
